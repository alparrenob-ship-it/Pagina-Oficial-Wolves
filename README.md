# Wolves Basketball Club

Landing page oficial de Wolves Basketball Club, diseñada como una experiencia deportiva moderna y responsive.

## Ejecutar localmente

```bash
python3 -m http.server 4173
```

Después visita `http://localhost:4173`.

## Estructura

- `index.html`: contenido y secciones principales.
- `styles.css`: identidad visual, layouts responsive y animaciones.
- `script.js`: navegación móvil, animaciones al hacer scroll y formulario del newsletter.
